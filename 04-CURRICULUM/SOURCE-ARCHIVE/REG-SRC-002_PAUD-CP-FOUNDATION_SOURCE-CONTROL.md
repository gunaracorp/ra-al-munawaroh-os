## Verbatim CP lock protocol

Before copying the three element statements into the canonical CP source file:
1. Download the PDF directly from the official URL.
2. Record publication/version metadata printed in the document and the retrieval date.
3. Check current official BSKAP/JDIH repository for a newer version or replacement.
4. Extract the exact element titles and complete CP statements verbatim, preserving punctuation and paragraph structure.
5. Compare extracted text to the rendered PDF pages; correct OCR errors.
6. Record page numbers for each element and calculate SHA-256 of the source PDF.
7. Have a second reviewer verify every copied sentence.
8. Only then mark the CP source as LOCKED; use the exact official wording in the crosswalk, and keep all local interpretations clearly labelled as internal design.
